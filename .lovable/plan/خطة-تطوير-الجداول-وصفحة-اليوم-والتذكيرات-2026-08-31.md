# خطة تطوير الجداول وصفحة اليوم والتذكيرات

## النتيجة المستهدفة
- تمييز بصري واضح بين **الموضوع** و**المهمة** داخل خلايا الجداول.
- تحويل `/today` إلى لوحة يوم وتقويم عملية تبدأ من التاريخ الحالي.
- توفير تذكير محلي فوري، مع Web Push حقيقي عند إغلاق التبويب على الأجهزة والمتصفحات المدعومة.
- احتساب تقدّم الأهداف من الجولات المكتملة ومقارنته بتقدّم المهام الفرعية أسبوعيًا.

## 1. بطاقات الجداول
- الإبقاء على بطاقة واحدة قابلة للسحب، مع شكلين واضحين:
  - الموضوع: طابع تنظيمي وأيقونة موضوع افتراضية، وشريط جانبي مميز.
  - المهمة: بطاقة تنفيذية تعرض الأولوية، الاستحقاق، والجولات المتبقية.
- تمكين اختيار أيقونة ولون لكل مهمة من منتقي النمط الموجود.
- فصل قائمة السياق حسب النوع:
  - المهمة: بدء جولة، الحالة، التقدّم، الأولوية، الاستحقاق، الأيقونة واللون، فتح التفاصيل.
  - الموضوع: فتح الموضوع، ربط المهام، الأيقونة واللون، النقل والأرشفة.
- الحفاظ على السحب والإفلات والتنقل بلوحة المفاتيح الحاليين.

## 2. تقويم `/today`
- جعل اليوم الحالي هو الاختيار الافتراضي دائمًا عند فتح الصفحة.
- إضافة تقويم شهري متكامل داخل الصفحة، مع مؤشرات على الأيام التي تحتوي مهامًا.
- عند اختيار يوم، يظهر جدول مبسط يحتوي: المهمة، الأولوية، وقت/تاريخ الاستحقاق، الجولات المقدرة، المكتملة، والمتبقية، وإجراء بدء الجولة.
- إبراز المتأخر والمستحق اليوم والقادم بصريًا، وإزالة رابط التقارير من واجهة اليوم لصالح التقويم والجدول.
- جعل `Alt+N` يفتح الالتقاط السريع مع اقتراح ذكي للمهمة/الجولة الأكثر تأخرًا وإجراء بدء مباشر، مع بقاء إنشاء مهمة أو ملاحظة ممكنًا.

## 3. التذكيرات المحلية وWeb Push
- إضافة مركز تذكيرات في الإعدادات لطلب الإذن وتحديد أوقات التنبيه قبل الاستحقاق.
- التذكير المحلي يعمل فورًا ما دام التطبيق/المتصفح نشطًا، ويعرض المهمة والجولات المتبقية وإجراء فتح `/today`.
- إضافة Messaging Service Worker مستقل لـ Web Push، مع تخزين اشتراك Push لكل مستخدم وإزالته عند إلغاء الإذن أو تسجيل الخروج.
- إضافة مهمة خادمية مجدولة محدودة الدفعة، آمنة من التكرار، تبحث عن المواعيد القريبة والجولات المتأخرة وترسل Push مرة واحدة لكل نافذة تذكير.
- الإشعار يفتح `/today` على اليوم والمهمة المقصودة، ويعمل خارج التبويب وعلى التطبيقات الأخرى حيث يدعم النظام Web Push.
- استخدام تذكير محلي كخيار احتياطي تلقائي إذا تعذر Push؛ iOS يتطلب تثبيت التطبيق على الشاشة الرئيسية ومنح الإذن.

## 4. احتساب الجولات والأهداف
- إضافة حقل صريح لنوع جلسة Pomodoro بدل الاعتماد على نص عنوان الجلسة، مع دعم السجلات القديمة.
- احتساب الجولات المكتملة لكل مهمة ثم المتبقية = `max(0, المقدّرة - المكتملة)`.
- اشتقاق تقدّم الهدف من مجموع الجولات المكتملة لمهامه ÷ مجموع الجولات المقدّرة، مع حد أقصى 100%.
- في التقرير الأسبوعي عرض ثلاثة مقاييس لكل هدف:
  - تقدّم الجولات الفعلي.
  - متوسط تقدّم المهام الفرعية.
  - الفجوة بينهما، مع عدد الجولات المكتملة/المقدّرة.
- عدم الكتابة فوق تقدّم المهمة اليدوي؛ المقارنة تبقى شفافة وتعرض كلا المقياسين.

## 5. البنية والبيانات
- تفعيل Lovable Cloud للجزء الخادمي الخاص بجدولة Web Push فقط، مع استمرار بيانات مساحة العمل الحالية كما هي وعدم نقلها.
- إضافة جداول اشتراكات Push، قواعد التذكير، وسجل الإرسال مع صلاحيات وصول مقيدة للمستخدم وخدمة الإرسال.
- إضافة مفاتيح VAPID كأسرار خادمية، وعدم كشف المفتاح الخاص في المتصفح.
- إضافة مفاتيح ترجمة عربية/إنجليزية لكل النصوص الجديدة.

## 6. التحقق
- اختبار تمييز البطاقات وقوائم السياق والسحب في الجدول.
- اختبار فتح `/today` على اليوم الحالي، تغيير اليوم، حساب الجولات المتبقية، وبدء الجولة.
- اختبار `Alt+N` من صفحة أخرى ومن `/today`.
- اختبار الإشعار المحلي، ثم Push من عامل الخدمة وفتح الرابط الصحيح.
- اختبار تقرير أسبوعي ببيانات هدف له عدة مهام وجولات، ثم فحص سطح المكتب والهاتف والبناء النهائي.

## ملاحظة تشغيلية
Web Push الحقيقي بعد إغلاق التبويب يحتاج نشر التطبيق وتشغيل الجدولة الخادمية؛ داخل معاينة Lovable سنختبر الواجهة والتذكير المحلي وتسجيل الاشتراك، ثم يُختبر الاستلام المغلق بعد النشر.
